# Hubejct OICP Integration MCP server

## Goal

MCP server dedicated to integration via Hubject (OICP v2.3) protocol as eMSP and CPO.

## Flow

Using oficial hubject documentations:

- CPO: [`Open Inter Charge Protocol - CPO docs`](https://github.com/hubject/oicp-cpo-2.3-api-doc)
- EMP: [`Open Inter Charge Protocol - EMP docs`](https://github.com/hubject/oicp-emp-2.3-api-doc)

Provide tools for AI Agents to search and retrieve information about OICP integration specific services, data schemas, modules etc.

## Stack

- Node v22+
- Typescript v5
- yarn v1
